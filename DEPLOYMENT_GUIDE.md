# PRODUCTION DEPLOYMENT GUIDE

## PART 1: BACKEND DEPLOYMENT ON RENDER (Render Web Service)

### 1. Root Directory Setting on Render
- **Root Directory**: `smart-hospital-backend`

### 2. Environment & Runtime
- **Environment**: `Java` (or `Docker` / `Maven`)
- **Java Version**: `17` or `21`

### 3. Build & Start Commands
- **Build Command**:
  ```bash
  mvn clean package -DskipTests
  ```
- **Start Command**:
  ```bash
  java -jar target/smart-hospital-backend-1.0.0.jar
  ```

### 4. Environment Variables on Render (Dashboard Settings)
Add these under **Environment Variables** in Render:

| Key | Example Value | Notes |
| :--- | :--- | :--- |
| `DB_URL` | `jdbc:mysql://YOUR_AIVEN_HOST:PORT/smart_hospital?sslMode=REQUIRED` | Your Aiven MySQL Cloud DB connection string |
| `DB_USERNAME` | `avnadmin` | Your Aiven DB username |
| `DB_PASSWORD` | `YOUR_AIVEN_PASSWORD` | Your Aiven DB password |
| `JWT_SECRET` | `404E635266556A586E3272357538782F413F4428472B4B6250645367566B5970` | 256-bit JWT secret key |
| `PORT` | `8080` | Service port |

## PART 2: FRONTEND DEPLOYMENT ON VERCEL (Vercel Web App)

### 1. Root Directory Setting on Vercel
- **Root Directory**: `smart-hospital-frontend`

### 2. Framework Preset
- **Framework Preset**: `Vite`

### 3. Build & Output Settings
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
- **Install Command**: `npm install`

### 4. Environment Variables on Vercel
Add this under **Environment Variables** in Vercel:

| Key | Value | Notes |
| :--- | :--- | :--- |
| `VITE_API_BASE_URL` | `https://your-render-backend-url.onrender.com/api` | The live URL generated by Render for your backend |
