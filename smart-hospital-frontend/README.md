# Smart Hospital Frontend

Modern React + Vite frontend for Smart Hospital Management System.

## Stack
- React.js
- Vite
- React Router DOM
- Axios
- Lucide Icons & Modern UI

## Setup & Running
1. Copy `.env.example` to `.env`:
   - `VITE_API_BASE_URL=http://localhost:8080/api`
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start dev server:
   ```bash
   npm run dev
   ```
4. Access app at `http://localhost:5173`
